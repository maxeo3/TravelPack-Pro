# 🧳 TravelPack Pro

Un'app web leggera per gestire le liste dei bagagli per i viaggi di famiglia.

## ✨ Caratteristiche
- **Preset Stagionali**: Liste pre-impostate per Estate e Inverno basate sulle esigenze di genitori, bambini e il cane Arya.
- **Calcolo Dinamico**: Calcola automaticamente la quantità di vestiti e pannolini in base ai giorni di viaggio.
- **Archivio**: Salva i tuoi viaggi nel browser per riprenderli in futuro.
- **Mobile First**: Progettata per essere usata comodamente da smartphone.
- **Privacy**: Nessun dato viene inviato a server; tutto rimane salvato localmente sul tuo dispositivo.

## 🚀 Come usarla
Apri l'app, inserisci meta e giorni, seleziona la stagione e inizia a spuntare gli oggetti!
